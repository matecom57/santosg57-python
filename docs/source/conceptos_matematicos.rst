Sistemas de Numeración
======================

**Sistemas de Numeración:**

* Números Naturales: :math:`\mathbb{N} = \{ 1, 2, 3, ... \}`

* Números Enteros: :math:`\mathbb{Z} = \{ ..., -4, -3, -2, -1, 0, 1, 2, 3, ... \}`

* Números Racionales: :math:`\mathbb{Q} = \{ \frac{p}{q} | p, q \in \mathbb{Z} \text{ y } q \neq 0  \}`

* Números Irracionales: :math:`\mathbb{I} = \{ \pi, -\sqrt{2}, e, ......  \}`

* Números Reales: :math:`\mathbb{R} = \mathbb{Q} \bigcup \mathbb{I}`
 
**Operadores de Comparación**

* :math:`< \leq, >, \geq, ==, !=`

**Operadores Lógicos**

* and, or

**Vectores**

Un vector esta dado por:

.. math::

   (x_1, x_2, ..., x_n)

donde :math:`x_i \in \mathbb{R}`, para i=1,...n

Decimos que el vector es de longitud n, y es un vector fila.

:math:`x_1` - primer componente

:math:`x_2` - segundo componente

:math:`x_i` - i-ésimo componente

Se define la suma entre vectores y multiplicación por un escalar de la siguiente manera:

* 1) :math:`(x_1, x_2, ..., x_n) + (y_1, y_2, ..., y_n) = (x_1+y_1, x_2+y_2, ..., x_n+y_n)`

* 2) :math:`c \times (x_1, x_2, ..., x_n) = (cx_1, cx_2, ..., cx_n)`

**Matrices**

Se define una matriz como:

.. math::

   \begin{pmatrix}
    a_{11} & a_{12} & ...  & a_{1n}  \\
    a_{21} & a_{22} & ...  & a_{2n}  \\
    ... & ... & ... & ... \\
    a_{m1} & a_{m2} & ...  & a_{mn}  \\
   \end{pmatrix}

Donde :math:`a_{ij} \in \mathbb{R}` con i=1,...,m y j=1,...,n

Decimos que la matriz es de tamaño :math:`m \times n`, m filas y n columnas.
