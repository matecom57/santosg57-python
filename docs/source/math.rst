Clase Math
==========

**Algunos métodos de la clase Math:**

``acos``, ``atan``, ``ceil``, ``cos``, ``degrees``, ``dist``, ``e``, ``exp``,  
``fabs``, ``factorial``, ``floor``, ``fsum``, ``hypot``, ``inf``, ``isinf``, 
``isnan``, ``log``, ``log10``, ``log2``, ``nan``, ``perm``, ``pi``, 
``pow``, ``prod`, ``radians``, ``remainder``, ``sin``, ``sqrt``, ``tan``

**Ejemplos**

.. code:: Python

   import math

   print(math.sqrt(16))

.. code:: Python

   from math import sqrt, pi

   print(sqrt(25))       # Output: 5.0
   print(pi)             # Output: 3.141592653589793

.. code:: Python

   import math as m
 
   print(m.floor(3.7))   # Output: 3
