Listas
======

Una lista es una estructura de datos definida por corchetes [ ].

**Ejemplos**

.. code:: Python

   x = [1,2,33,5,6,7,8]
   
   y = []

   z = ['Juan', 'Pedro', 'Maria']

   w = [x, z]   # ``w`` es la variable construida a partir de las variables `x` y y


**Algunos methodos:**

``append``, ``clear``, 'copy', 'count', 'extend', 'index', 'insert', 'pop', 'remove', 'reverse', 
'sort'
